# Telegram Account Cleaner (юзербот)

Скрипт для **своего взломанного** Telegram-аккаунта. Входит в аккаунт (по номеру или по QR) и:

1. **Завершает все чужие сессии** (выкидывает взломщика).
2. **Покидает все каналы и группы** (свои — может удалить полностью, `--delete-owned`).
3. **Удаляет все чаты и чаты с ботами** (боты можно заблокировать, `--block-bots`).
4. **Удаляет все контакты**.
5. По желанию — **удаляет аккаунт** (`--delete-account`).

Работает «как человек»: случайные паузы 1.5–4 c между действиями и автоматическое ожидание при FloodWait, чтобы Telegram не заблокировал.
Чат «Избранное» и служебный чат Telegram (777000, туда приходят коды) не трогаются.

## 1. API_ID и API_HASH — НЕ обязательны
Если my.telegram.org не пускает («too many tries»), ничего не делайте: скрипт сам возьмёт
публичные ключи официального Telegram Desktop (они открыты в его исходном коде).
Свои ключи можно задать через `TG_API_ID` / `TG_API_HASH`, если они есть.

**Если код входа не приходит из-за многих попыток** — используйте вход по QR (`--login qr`):
код не нужен, достаточно телефона, где Telegram ещё открыт.

## 2. Установка на сервере
```bash
cd tg_cleaner
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# (необязательно) export TG_API_ID=123456
# (необязательно) export TG_API_HASH=abcdef0123456789
```

## 3. Сначала просмотр (ничего не удаляет)
```bash
python cleaner.py --dry-run
```

## 4. Запуск
Вход по QR (Telegram на телефоне → Настройки → Устройства → Подключить устройство):
```bash
python cleaner.py --login qr --block-bots
```
Вход по номеру (код + облачный пароль 2FA):
```bash
python cleaner.py --login phone --phone +998XXXXXXXXX --block-bots
```

| Флаг | Что делает |
|---|---|
| `--dry-run` | только показать, что будет удалено |
| `--delete-owned` | свои каналы/группы удалить полностью, а не просто выйти |
| `--revoke` | удалять переписку и у собеседника |
| `--block-bots` | блокировать ботов |
| `--keep-contacts` | не удалять контакты |
| `--skip-sessions` | не завершать чужие сессии |
| `--delete-account` | в конце удалить аккаунт (с подтверждением) |
| `--min-delay/--max-delay` | паузы между действиями |

## Важно
- **Telegram не даёт завершать чужие сессии с новой сессии первые ~24 часа** (`FRESH_RESET_AUTHORISATION_FORBIDDEN`). Скрипт это сообщит — запустите его повторно через сутки (файл `cleaner.session` сохраняет вход).
- После чистки сразу **включите/смените облачный пароль (2FA)**: Настройки → Конфиденциальность → Облачный пароль.
- Файл `cleaner.session` = доступ к аккаунту. Никому не передавайте, после работы удалите.

## Постоянное слежение (--watch)
После разовой чистки бот остаётся работать и **автоматически убирает всё новое**:
как только вы (или взломщик) оказались в любом канале/группе — бот из него выходит;
любой новый чат или бот — удаляет; любое новое сообщение (в т.ч. код/смс) — удаляет у всех.
Не трогает «Избранное» и служебный чат Telegram 777000.

```bash
python cleaner.py --login qr --block-bots --watch
```
Остановить — Ctrl+C. Чтобы бот работал постоянно даже после закрытия терминала:
```bash
nohup python cleaner.py --block-bots --watch >> watch.log 2>&1 &
```
