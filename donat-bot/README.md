# Автодонат-бот для Telegram (бот + мини-приложение)

Бот для продажи доната (Free Fire, PUBG UC, другие игры, сервисы, Telegram Stars/Premium) с мини-приложением, балансом,
оплатой по чеку и автоматической выдачей через API поставщика.

## Что умеет

**Бот в чате**
- `/start` — приветствие и главное меню: Пополнить донат, Магазин, Настройка чувствительности FF, Профиль, О нас,
  Поддержка, Отзывы, Язык (тоҷикӣ / русский), Валюта (сомони / рубли).
- Кнопка «📋 Меню» внизу и кнопка «Мағоза» слева от поля ввода (открывает мини-приложение).
- Заявка на оплату: номер `TOP-XXXX`, сумма с уникальными копейками, номер карты (копируется нажатием), инструкция.
  Клиент присылает фото чека — бот пересылает его админам с кнопками ✅ / ❌.
- Партнёрская программа: ссылка `?start=ref_<id>`, процент с каждой покупки друга на баланс.

**Мини-приложение**
- Главная: приветствие по времени суток, баланс (можно скрыть), «Пур кардан», «Таърих», поиск по каталогу,
  баннеры категорий, списки игр.
- Страница игры: вкладки (Алмазҳо / Level Up), выбор нескольких товаров, карточки с ценой.
- Оформление: ID игрока с кнопкой «Вставить», способ оплаты (баланс, Алиф, Душанбе Сити, другие банки,
  перевод из России, банкомат), согласие с условиями.
- Пополнение баланса: суммы 10–1000 см, пересчёт в рубли по курсу.
- История: заказы с фильтрами (ожидание / выполнено / отмена) и финансы.
- Профиль: уровень покупателя, статистика, партнёрская программа, тема, язык, валюта, PIN-код.
- Уведомления, поддержка с FAQ, генератор чувствительности FF.

**Админ** (ID из `ADMIN_IDS`)
- Подтверждение/отклонение чеков кнопками. После подтверждения баланс пополняется, а связанный заказ сразу
  оплачивается и уходит поставщику.
- Если поставщик не настроен или вернул ошибку — заказ приходит админу с кнопками «✅ Иҷро шуд», «🔁 API», «↩️ Бозгашт».
- `/admin` — панель и статистика, `/pending`, `/products`, `/setprice`, `/hide`, `/show`, `/balance`,
  `/ban`, `/unban`, `/say`, `/broadcast`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите Python 3.11+ и зависимости:
   ```bash
   cd donat-bot
   python3 -m venv venv && . venv/bin/activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните: `BOT_TOKEN`, `ADMIN_IDS`, номера карт, ссылки поддержки.
4. Мини-приложению нужен **HTTPS-адрес**. Сервер слушает порт `WEB_PORT` (8080). Варианты:
   - VPS + домен + nginx/Caddy с SSL, проксирующий на `127.0.0.1:8080`;
   - для теста — `cloudflared tunnel --url http://localhost:8080` и полученный адрес в `WEBAPP_URL`.
5. Запуск: `python run.py`.

Без `WEBAPP_URL` бот работает, но кнопки мини-приложения показывают предупреждение.

## Поставщик (автовыдача)

Вся работа с поставщиком — в `app/supplier.py`. Сейчас там универсальный HTTP-адаптер:
`POST {SUPPLIER_API_URL}/order` с `{product, player_id, quantity, external_id}` и ключом в заголовке.
У каждого поставщика свой API, поэтому, когда выберете поставщика, адаптер нужно подогнать под его документацию,
а в `app/catalog.py` заполнить поле `sku` (код товара у поставщика) для каждого товара.
Пока `SUPPLIER_API_URL`/`SUPPLIER_API_KEY` пустые, все заказы выдаются вручную через админа.

## Каталог и цены

Базовые цены — в `app/catalog.py` (в сомони). Менять цену без перезапуска: `/setprice ff_cis_572 44.20`.
Найти id товара: `/products 572`. Название магазина — `SHOP_NAME` в `.env`.

## Структура

```
donat-bot/
  run.py               запуск
  app/config.py        настройки из .env, способы оплаты
  app/db.py            SQLite: пользователи, заказы, заявки, транзакции, уведомления
  app/catalog.py       категории и товары
  app/services.py      логика: заказы, оплата, выдача, рефералы, уровни
  app/supplier.py      адаптер API поставщика
  app/handlers/        обработчики бота (user, admin)
  app/web.py           API мини-приложения (проверка Telegram initData)
  webapp/              мини-приложение (HTML/CSS/JS без сборки)
```
